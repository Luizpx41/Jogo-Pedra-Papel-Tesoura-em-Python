# Jogo-Pedra-Papel-Tesoura-em-Python
Esse foi um projeto simples de um mini-jogo pedra/papel/tesoura feito em python. Nele utilizei o livro Ensine seus filhos a programar (Editora Novatec) de Bryson Payne.
Nesse livro além dos conceitos básicos de variáveis, você aprende a criar jogos simples e intuitivos. A leitura juntamente com a prática, me ajudaram a conhecer mais a linguagem python.

Para poder usufruir da leitura/prática que está presente no livro, é essencial que o Python seja baixado no seu computador. Ele pode ser encontrado no site: https://www.python.org/
